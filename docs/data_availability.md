# Data Availability

ATB is released as a synthetic matched-control benchmark artifact.

## Included in the Public Repository

- Experiment 1 dataset and committed release outputs
- Experiment 2 dataset and committed release outputs
- committed model response ledgers used for the public artifact
- audit files, robustness files, baseline ladder files, and release reports

## Excluded from the Public Repository

The public release intentionally excludes local process files, local environment files, secret-bearing files, and older pilot materials that are not part of the current release framing.

## Claim Boundary

The repository provides synthetic benchmark artifacts only. It does not provide real-world validated field data.
